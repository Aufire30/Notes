# 颜色通道的转换

```python
import matplotlib.pyplot as plt
%matplotlib inline
plt.imshow(result[0].plot()[:,:,::-1])
```

代码中的 `[:, :, ::-1]` 是 NumPy 数组切片操作，主要用于将图像的 **BGR 颜色通道翻转为 RGB 格式**。

具体拆解与作用如下：

### 1. 切片语法拆解

* **第 1 个 `:`**：保留图像的所有高度像素（行）。
* **第 2 个 `:`**：保留图像的所有宽度像素（列）。
* **第 3 个 `::-1`**：对颜色通道维进行**倒序翻转**（将通道顺序从索引 `[0, 1, 2]` 变为 `[2, 1, 0]`）。

---

### 2. 为什么要这么做？
* **`result[0].plot()`**（通常是 Ultralytics YOLO 等目标检测库）生成的图像 NumPy 数组默认采用 **BGR**（蓝、绿、红）通道顺序（OpenCV 常用格式）。
* **`plt.imshow()`**（Matplotlib 绘图库）默认读取和显示的图像通道顺序是 **RGB**（红、绿、蓝）。

如果没有 `[:, :, ::-1]` 进行通道转换，直接用 `plt.imshow()` 显示 BGR 图像会导致**颜色倒置**（例如原本红色的物体显示为蓝色，人脸颜色发青/发蓝）。使用 `[:, :, ::-1]` 可以将 BGR 快速转为 RGB，保证显示的图像颜色正常。
