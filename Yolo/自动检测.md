# 通过终端指令进行检测

- **测试图片检测**

  ```bash
  yolo predict model=yolov8n.pt source='test.jpg'
  ```

* **测试视频检测（生成标注后的新视频）：**
  ```bash
  yolo predict model=yolov8n.pt source='test.mp4'
  ```
* **调用电脑自带摄像头实时检测（输入 `0`）：**
  ```bash
  yolo predict model=yolov8n.pt source=0
  ```

- **检测电脑屏幕**

  ```bash
  yolo predict model=yolov8n.pt source='screen'
  ```
