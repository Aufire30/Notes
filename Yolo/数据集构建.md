# 视频抽帧

```python
video = cv2.VideoCapture("test.mp4")
num = 0             # 计数器
save_step = 30      # 间隔帧
while True:
    ret,frame = video.read()
    if not ret:
        break
    num += 1
    if num % save_step == 0:
        cv2.imwrite("video_img/" + str(num//30) + ".jpg",frame)
```

# labelimg数据集标注

> [!CAUTION]
>
> 正常安装后，`labelImg` 源码在画框（绘制十字线和矩形框）时，向 Qt 绘图库（PyQt5）传递了**浮点数 (float)** 坐标。而在新版本的 PyQt5 中，绘图函数严格要求必须传递**整数 (int)** 坐标。因此一旦按下 `W` 键或者拖动鼠标画框，程序就会报 `TypeError` 类型错误并瞬间闪退。
>
> 
>
> ## 解决方法
>
> #### 方法一：降低 Python/PyQt5 版本重新创建环境（最推荐，省心）
>
> 直接创建一个 **Python 3.8** 的虚拟环境，并锁定较稳定的 `PyQt5` 版本，该问题会自动消除：
>
> 1. **重新创建一个 Python 3.8 环境：**
>
>    ```bash
>    conda create -n labelimg_py38 python=3.8 -y
>    
>    conda activate labelimg_py38
>    ```
>
> 2. **指定版本安装：**
>
>    ```
>    bash
>    
>    
>    
>    
>    
>    pip install PyQt5==5.15.2 labelimg -i https://pypi.tuna.tsinghua.edu.cn/simple
>    ```
>
> 3. **重新启动：**
>
>    ```bash
>    labelimg
>    ```
>
> ------
>
> #### 方法二：直接修改 `labelImg` 源码（无需重建环境）
>
> 如果你不想重新建环境，可以直接修改 `labelImg` 库里的文件，将坐标强转为整数 `int()`：
>
> 1. **找到安装路径下的 `canvas.py` 文件**： 文件通常位于你的 Anaconda 虚拟环境路径中： `C:\Users\你的用户名\.conda\envs\你的环境名\Lib\site-packages\libs\canvas.py` （或者 `Anaconda3\envs\你的环境名\Lib\site-packages\libs\canvas.py`）
>
> 2. **用 VS Code 或记事本打开 `canvas.py`**： 定位到第 520~535 行附近的 `paintEvent` 函数。
>
> 3. **找到以下三行代码并进行修改**：
>
>    - 原代码：
>
>      ```python
>      p.drawRect(left_top.x(), left_top.y(), rect_width, rect_height)
>      
>      p.drawLine(self.prev_point.x(), 0, self.prev_point.x(), self.pixmap.height())
>      
>      p.drawLine(0, self.prev_point.y(), self.pixmap.width(), self.prev_point.y())
>      ```
>
>    - 修改为（加入 `int()` 强转）：
>
>      ```python
>      p.drawRect(int(left_top.x()), int(left_top.y()), int(rect_width), int(rect_height))
>      
>      p.drawLine(int(self.prev_point.x()), 0, int(self.prev_point.x()), int(self.pixmap.height()))
>      
>      p.drawLine(0, int(self.prev_point.y()), int(self.pixmap.width()), int(self.prev_point.y()))
>      ```
>
> 4. 保存文件后，重新在终端运行 `labelimg` 即可顺畅画框。
