# YOLO 全局配置与参数详解手册 (`default.yaml`)

本文档汇总整理自 Ultralytics YOLO 官方核心配置文件 [`default.yaml`](file:///C:/Users/Aufire/Desktop/Yolo/ultralytics-main/ultralytics/cfg/default.yaml)，详细涵盖任务模式、训练微调、预测推理、可视化渲染、验证评估、模型导出、损失函数超参数及数据增强参数等全部配置项。

## 1. 基础全局配置与任务模式 (Tasks & Modes)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `task`            | `str`           | `detect` | 指定 YOLO 任务类型。可选值包括：`detect`（目标检测）、`segment`（实例分割）、`classify`（图像分类）、`pose`（姿态估计）、`obb`（旋转框检测）、`semantic`（语义分割）、`depth`（深度估计）。 |
| `mode`            | `str`           | `train`  | 指定 YOLO 运行模式。可选值包括：`train`（模型训练）、`val`（验证评估）、`predict`（推理预测）、`export`（模型导出）、`track`（目标追踪）、`benchmark`（性能基准测试）。 |
| `cfg`             | `str`           | `None`   | 自定义配置文件（YAML）路径。传入后可用自定义参数覆盖默认的配置项。 |

## 2. 预测与推理配置参数 (Predict / Inference)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `source`          | `str` / `int`   | `None` | 指定推理数据源。支持本地图像/视频路径、图片目录、网络 URL，或实时摄像头设备 ID（如 `0`）。未指定时会报警并降级使用内置演示资源。 |
| `conf`            | `float`         | `0.25` | 最小置信度阈值。只保留概率大于等于该值的检测框，调高此值可大幅减少误报（假阳性预测）。*(注：预测时默认为 0.25，验证时默认为 0.001)* |
| `iou`             | `float`         | `0.7`  | 非极大值抑制（NMS）的交并比（IoU）阈值。较低的数值会更严格地消除重叠框，避免同一目标重复检测。 |
| `imgsz`           | `int` / `list`  | `640`  | 推理输入分辨率。指定单整数 `N` 会放缩至 `N×N` 正方形；也可传入 `[高度, 宽度]` 格式元组或列表。 |
| `rect`            | `bool`          | `False`| 矩形推理开关。设为 `True` 时，同一批次在后端支持的情况下将采用最小矩形填充以提升推理速度；设为 `False` 强制补全为完整 `imgsz` 正方形。 |
| `quantize`        | `int` / `str`   | `None` | 推理量化精度选择。GPU 推理可设为 `16` / `"fp16"` 开启半精度，`32` / `"fp32"` 为单精度。导出为 INT8/PTQ 量化后加载对应模型使用。 |
| `device`          | `int` / `str`   | `None` | 指定推理硬件计算设备。例如：单卡 `0`、多卡 `[0,1]`、NVIDIA GPU `'cuda:0'`、华为昇腾 `'npu:0'`、Intel `'xpu:0'`、CPU `'cpu'`。 |
| `dnn`             | `bool`          | `False`| ONNX 推理后端开关。设为 `True` 时使用 OpenCV 的 DNN 模块执行 ONNX 推理，而非默认的 ONNX Runtime 引擎。 |
| `data`            | `str`           | `None` | 数据集定义文件（YAML）路径（如 `coco8.yaml`）。仅在第三方模型缺失元数据导致分类名称无法自动读取时，用于补全类别名称。 |
| `batch`           | `int`           | `1`    | 预测批处理大小（Batch Size）。仅在数据源为目录、视频或文本文件列表时生效。较大批次可提升整体算力吞吐量。 |
| `max_det`         | `int`           | `300`  | 每张图像允许的单次最大检测框数量上限，防止密集场景中输出冗余或过多的噪声结果。 |
| `vid_stride`      | `int`           | `1`    | 视频帧步进读取间隔。设为 `1` 表示处理每一帧；增大数值可以跳帧处理，牺牲连续性以换取处理速度提升。 |
| `stream_buffer`   | `bool`          | `False`| 视频流缓冲队列策略。设为 `False` 会丢弃旧帧以保证最新画面处理（适合低延迟实时系统）；设为 `True` 将新帧入队列缓冲，确保不漏帧但可能增加延迟。 |
| `visualize`       | `bool`          | `False`| 激活热图生成开关。设为 `True` 时保存类激活热力图（Heatmap），直观呈现影响模型推理类别的关键像素分布。仅支持 PyTorch 原生模型。 |
| `augment`         | `bool`          | `False`| 测试时数据增强（TTA）。开启后对输入多尺度与翻转融合预测，可牺牲小部分时间提升检测的鲁棒性与精度。 |
| `agnostic_nms`    | `bool`          | `False`| 跨类别 NMS。开启后不在不同类别间保留重叠框，对所有类别统一按最高置信度抑制；对端到端模型（如 YOLOv10/YOLO26）用于滤除相同位置的重复标签（IoU=1.0）。 |
| `classes`         | `int` / `list`  | `None` | 类别筛选过滤器。传入特定类别 ID 数组（如 `0` 或 `[0, 2, 3]`），推理结果中仅过滤返回指定的目标类别。 |
| `retina_masks`    | `bool`          | `False`| 高分辨率分割掩码（仅分割任务）。开启后将输出与原图原始尺寸对齐的高清晰度实例分割掩码（Masks）。 |
| `embed`           | `list[int]`     | `None` | 特征向量提取层。指定神经网络层的索引列表，模型预测时将直接返回该层的特征嵌入（Embeddings），适合聚类与相似度检索等下游任务。 |
| `compile`         | `bool` / `str`  | `False`| PyTorch 2.x 计算图编译加速。支持 `True`（使用 default 模式）、`False`（禁用），或模式字符串（如 `"reduce-overhead"`）。 |
| `channels_last`   | `bool`          | `False`| 通道后置（NHWC）内存布局。开启后利用 NVIDIA Tensor Core 硬件特性加速 GPU 卷积运算，不影响输出结果。仅支持 CUDA 场景。 |
| `end2end`         | `bool`          | `None` | 端到端推理覆盖。对原生支持无 NMS 推理的模型（如 YOLOv10、YOLO26），设为 `False` 可关闭端到端并回退到传统 NMS 后处理管线（支持调用 `iou` 参数）。 |

## 3. 预测渲染与可视化设置 (Visualize & Display)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `show`            | `bool`          | `False`| 实时窗口展示。开启后自动弹出图形 GUI 窗口并实时渲染预测图像或视频结果。 |
| `save_frames`     | `bool`          | `False`| 视频独立帧保存。在对视频源进行推理时，将视频每一帧处理结果单独保存为独立的图片文件。 |
| `save_txt`        | `bool`          | `False`| 导出 `.txt` 标注文件。将目标检测框坐标以标准 YOLO 归一化文本格式（`cls x_center y_center width height`）保存。 |
| `save_conf`       | `bool`          | `False`| 导出置信度得分。开启 `save_txt` 时，同步将各目标预测框的 Confidence 置信度数值写入文本末尾。 |
| `save_crop`       | `bool`          | `False`| 保存截取的预测小图。自动按边界框裁剪图片中识别出的目标，并分别保存到对应类别名称的子文件夹中。 |
| `show_labels`     | `bool`          | `True` | 渲染类别名称标签。在图像检测框上方绘制分类名称文本（如 `'person'`）。 |
| `show_conf`       | `bool`          | `True` | 渲染置信度概率。在图像检测框标签旁绘制具体识别置信度数值（如 `'0.99'`）。 |
| `show_boxes`      | `bool`          | `True` | 渲染检测边界框（Bounding Boxes）。在预测图上画出目标的矩形选框。 |
| `line_width`      | `int`           | `None` | 检测框线条粗细。显式设定所有检测边界框与文字标签的描边宽度（像素）；留空 `None` 则根据图像分辨率自动缩放适配。 |

## 4. 模型训练与微调配置 (Train Settings)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `model`           | `str`           | `None` | 训练使用的模型配置文件（`.yaml`）或已预训练的权重文件（`.pt`）路径。 |
| `epochs`          | `int`           | `100`  | 训练的总迭代轮次（Epochs）。 |
| `time`            | `float`         | `None` | 最长训练计时限制（单位：小时）。若设定该值，优先级高于 `epochs`，达到设定时长后自动停止并保存。 |
| `patience`        | `int`           | `100`  | 早停法（Early Stopping）容忍轮数。当验证指标连续 N 个 Epoch 没有提升时，触发提前终止以防止过拟合。 |
| `save`            | `bool`          | `True` | 训练中间权重检查点（Checkpoint）及评估图表保存总开关。 |
| `save_period`     | `int`           | `-1`   | 检查点保存周期。设为大于 0 的整数 N 表示每训练 N 轮保存一次权重文件（`-1` 表示仅保存 `best.pt` 和 `last.pt`）。 |
| `cache`           | `bool` / `str`  | `False`| 数据集图像缓存策略。`True` 或 `'ram'` 将所有训练图像常驻内存以极致加速读取；`'disk'` 缓存在硬盘；`False` 关闭缓存。 |
| `workers`         | `int`           | `8`    | 多进程数据加载器 DataLoader 工作线程数量（使用 DDP 多卡分布式训练时为单 RANK 的工作线程数）。 |
| `project`         | `str`           | `None` | 保存实验输出成果的根文件夹路径。 |
| `name`            | `str`           | `None` | 本次训练实验的具体名称，输出将存储于 `project/name` 目录下。 |
| `exist_ok`        | `bool`          | `False`| 设为 `True` 时允许直接覆盖已存在的 `project/name` 文件夹，而不会自动重命名为 `name2`。 |
| `pretrained`      | `bool` / `str`  | `True` | 是否加载预训练权重。设为 `True` 自动下载加载对应官方权重，也可传入字符串路径指定本地特定权重文件。 |
| `cls_remap`       | `bool`          | `True` | 微调类别自动重映射。跨不同数据集微调时，通过类名精准对齐并重新映射预训练分类头中的权重通道。 |
| `optimizer`       | `str`           | `auto` | 选择优化器类型。可选：`SGD`、`MuSGD`、`Adam`、`Adamax`、`AdamW`、`NAdam`、`RAdam`、`RMSProp`，或 `auto` 自动匹配。 |
| `verbose`         | `bool`          | `True` | 详细输出打印控制。控制控制台是否打印每轮的详细 Loss 和评估统计指标日志。 |
| `seed`            | `int`           | `0`    | 全局随机种子（Random Seed），固定随机算法以确保模型训练过程可高度复现。 |
| `deterministic`   | `bool`          | `True` | 确定性算法模式。强制启用 PyTorch CUDNN 的确定性计算，保证实验完全可复现（可能会带来极微小的速度下降）。 |
| `single_cls`      | `bool`          | `False`| 单类别训练模式。将多类别数据集中的所有类别统一忽略并强制视作单个类别（Class 0）训练。 |
| `cos_lr`          | `bool`          | `False`| 学习率调度策略。开启余弦退火（Cosine Annealing）学习率衰减，关闭则使用标准线性衰减策略。 |
| `close_mosaic`    | `int`           | `10`   | 倒数 N 轮禁用 Mosaic 马赛克增强。在训练最后 N 个 Epoch 自动关闭 Mosaic 数据增强，助模型适应自然图像分布并加速收敛。 |
| `resume`          | `bool`          | `False`| 断点续训开关。从最后保存的 `last.pt` 检查点中无缝恢复模型参数、优化器状态并继续训练。 |
| `amp`             | `bool`          | `True` | 自动混合精度训练（AMP）。开启 FP16/BF16 混合精度计算，大幅降低显存占用并提升显卡计算效率。 |
| `fraction`        | `float`         | `1.0`  | 投入训练的数据集切片比例（取值范围 `0.0 < fraction <= 1.0`）。设为 `0.1` 表示抽取 10% 训练集快速验证代码。 |
| `profile`         | `bool`          | `False`| 性能基准剖析。训练期间剖析 ONNX/TensorRT 推理耗时及速度，并将数据推送到日志记录器。 |
| `freeze`          | `int` / `list`  | `None` | 网络层参数冻结。传入整数 N 表示冻结模型前 N 层特征提取层；传入列表（如 `[0, 1, 2]`）精确冻结指定层。 |
| `multi_scale`     | `float`         | `0.0`  | 多尺度训练拉伸幅度。在基础 `imgsz` 尺寸上按指定比例随机放缩图形分辨率，增强模型对多尺度目标的适应力。 |
| `overlap_mask`    | `bool`          | `True` | （分割专属）训练掩码重叠融合。在实例分割训练中，将属于同一图像的多目标实例 Mask 融合拼接到单张大图中。 |
| `mask_ratio`      | `int`           | `4`    | （分割专属） Mask 训练计算下采样缩放比例。 |
| `dropout`         | `float`         | `0.0`  | （分类专属）分类网络全连接头的 Dropout 随机丢弃率，取值 `0.0~1.0`。 |

## 5. 验证与测试评估设置 (Val/Test Settings)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `val`             | `bool`          | `True` | 训练伴随验证。设为 `True` 时在训练每轮 Epoch 结束后自动触发验证集性能评估。 |
| `split`           | `str`           | `val`  | 评估时使用的数据划分子集。可选 `val`（验证集）、`test`（测试集）或 `train`（训练集）。 |

## 6. 模型导出配置参数 (Export Settings)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `format`          | `str`           | `torchscript` | 指定的目标导出模型格式。支持：`onnx`、`openvino`、`engine` (TensorRT)、`torchscript`、`coreml`、`saved_model`、`pb`、`tflite`、`edgetpu`、`paddle`、`mnn`、`ncnn`、`rknn`、`executorch`、`ascend` 等。 |
| `keras`           | `bool`          | `False`| TF 算子转换选项。仅当 `format=saved_model` 导出 TensorFlow 框架模型时开启 Keras 架构层转义。 |
| `optimize`        | `bool`          | `False`| DEEPX 工具链专属优化。开启深度编译级优化，延长模型编译构建耗时以换取极致的边缘端推理性能。 |
| `dynamic`         | `bool`          | `False`| 动态尺寸支持。为 ONNX、TensorRT、TorchScript、OpenVINO 等格式开启动态轴（Dynamic Shape），允许运行时改变输入维度。 |
| `simplify`        | `bool`          | `True` | ONNX 结构化简化。在生成 ONNX 文件时调用 `onnx-simplifier` 进行拓扑算子融合剪枝，去除无用算子节点。 |
| `opset`           | `int`           | `None` | 指定中间 ONNX 算子集中使用的 Opset 版本号（例如 `11`、`12`、`17` 等）。 |
| `workspace`       | `float`         | `None` | TensorRT 构建空间。构建 TensorRT Engine 时分配使用的显存上限容量（单位 GiB，例如设为 `4`）。 |
| `nms`             | `bool`          | `False`| 导出内嵌 NMS。把 NMS 算子直接编译包含进导出好的模型内部（后端需支持支持），运行推理时免去调用外部 NMS。 |

## 7. 优化器、学习率与损失函数超参数 (Hyperparameters)

| 参数名 (Argument) | 数据类型 (Type) | 默认值 | 功能说明 |
| :---------------- | :-------------- | :----- | :----------------------------------------------------------- |
| `lr0`             | `float`         | `0.01` | 基础初始学习率（Initial Learning Rate）。SGD 默认 0.01，Adam/AdamW 默认 1e-3。 |
| `lrf`             | `float`         | `0.01` | 学习率衰减最小终点比例（最终学习率计算式为 `lr0 * lrf`）。 |
| `momentum`        | `float`         | `0.937`| 动量因子。对应 SGD 的 Momentum 或 Adam 优化器的 Beta1。 |
| `weight_decay`    | `float`         | `0.0005`| 权重衰减惩罚系数（L2 正则化），用于降低模型过拟合风险。 |
| `warmup_epochs`   | `float`         | `3.0`  | 热身阶段（Warmup）的训练轮数，支持小数（如 3.5）。 |
| `warmup_momentum` | `float`         | `0.8`  | 学习率热身阶段的起始初始动量（Warmup Momentum）。 |
| `warmup_bias_lr`  | `float`         | `0.1`  | 热身阶段专门分配给网络层偏置参数（Bias）的学习率上限。 |
| `distill_model`   | `str`           | `None` | 知识蒸馏教师模型（Teacher Model）路径。指定后开启蒸馏训练逻辑。 |
| `dis`             | `float`         | `6.0`  | 知识蒸馏损失函数（Distillation Loss）计算比例权重。 |
| `box`             | `float`         | `7.5`  | 目标边界框位置回归损失（Bounding Box Loss）算子在总 Loss 中的权重系数。 |
| `cls`             | `float`         | `0.5`  | 类别判定分类损失（Classification Loss）算子在总 Loss 中的权重系数。 |
| `cls_pw`          | `float`         | `0.0`  | 分类长尾极不平衡分布的正样本权重乘幂指数（`0.0` 关闭，`1.0` 开启全频率反比加权）。 |
| `dfl`             | `float`         | `1.5`  | 分布焦点损失（Distribution Focal Loss, DFL）在总 Loss 中的权重系数。 |
| `pose`            | `float`         | `12.0` | 姿态关键点定位 Loss 增益权重（仅姿态估计 Task 触发）。 |
| `kobj`            | `float`         | `1.0`  | 姿态关键点目标存在度 Loss 增益权重（仅姿态估计 Task 触发）。 |
| `rle`             | `float`         | `1.0`  | 残差似然估计损失（Residual Log-likelihood Estimation Loss）权重系数。 |
| `angle`           | `float`         | `1.0`  | 旋转边框倾斜角度 Loss 增益权重（仅 OBB 旋转框检测 Task 触发）。 |
| `dlog`            | `float`         | `1.0`  | 深度对数误差损失（SILog Loss）增益权重（仅 Depth 深度估计 Task 触发）。 |
| `dgrad`           | `float`         | `0.5`  | 深度梯度梯度一致性 Loss 增益权重（仅 Depth Task 触发）。 |
| `dlam`            | `float`         | `1.0`  | 深度估计中的对数方差平滑聚焦度（`1.0` 尺度无关，`0.0` 聚焦 RMSE）。 |
| `nbs`             | `int`           | `64`   | 标称基准批大小（Nominal Batch Size）。用于消除不同真实 `batch` 大小引起的梯度累计与损失尺度偏差。 |
