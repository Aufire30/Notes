# 线性回归

## 线性回归的批量梯度下降

### 1. 问题背景：线性回归模型

线性回归的目标是拟合一条直线（或超平面）来预测连续值，模型形式为：

![image-20260518092233479](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260518092233479.png)

其中：

- w：权重（斜率），控制输入特征 x 对预测值的影响；
- b：偏置（截距），调整直线的整体位置；
- `predict(x[i])` 函数就是实现这个公式，返回预测值 y^。

------

### 2. 核心目标：最小化损失函数

我们用 **均方误差（MSE, Mean Squared Error）** 作为损失函数，衡量模型预测值与真实值的偏差：![image-20260518092320769](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260518092320769.png)

- n：样本总数；
- y^i：模型对第 i 个样本的预测值；
- yi：第 i 个样本的真实标签；
- 代码中 `pow(predict(x[i]) - y[i], 2)` 就是计算单个样本的平方误差，最后除以 n 得到平均损失。
- 代码中`loss /= n`只除了n，没有除2n是因为省略了2(除以 2n 只是给损失函数乘了一个常数系数 1/2，它不会改变损失函数的**最小值点**，也不会影响梯度下降找到最优解。你也可以除以 n，只是梯度里会多一个 2，最终的收敛结果是一样的。)

训练的目标就是找到最优的 w 和 b，让这个损失函数的值尽可能小。

------

### 3. 核心算法：批量梯度下降（BGD）

梯度下降是一种迭代优化算法，通过沿着损失函数的**负梯度方向**更新参数，逐步逼近损失函数的最小值。

#### 3.1 梯度的计算（核心）

损失函数对参数 w 和 b 的偏导数（梯度）决定了参数更新的方向和步长：

- 对 b 的梯度：

![image-20260518092402433](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260518092402433.png)

代码中：

- `dw += error * x[i]`：累加所有样本对 w 的梯度贡献；
- `db += error`：累加所有样本对 b 的梯度贡献；
- `error = y_pred - y[i]` 就是 (y^i−yi)，代码省略了常数系数 2（它会被学习率 lr 吸收，不影响优化方向）。

#### 3.2 参数更新规则

计算完所有样本的梯度后，用**平均梯度**更新参数：

![image-20260518092437872](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260518092437872.png)

代码中：

- `lr`：学习率，控制每次参数更新的 “步长”，太大容易震荡不收敛，太小则收敛过慢；
- `dw / n` 和 `db / n`：对梯度取平均，避免样本量过大时梯度过大导致更新不稳定。

------

### 4. 训练流程（Epoch 循环）

- **Epoch**：指用全部数据集完整训练一次的过程，代码中 `epochs` 就是训练的总轮数。
- 每一轮 Epoch 的步骤：
  1. 初始化梯度 `dw` 和 `db` 为 0；
  2. 遍历所有样本，累加每个样本的梯度贡献；
  3. 用平均梯度更新参数 w 和 b；
  4. （可选）定期计算并打印当前的 MSE 损失，监控训练进度。

------

### 5. 批量梯度下降的特点

- **优点**：梯度方向由所有样本共同决定，更新方向稳定，能保证收敛到全局最小值（线性回归的损失函数是凸函数，没有局部最优）；
- **缺点**：每次更新都需要遍历全部样本，当数据集很大时，计算效率低，内存占用高。
