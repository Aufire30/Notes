## 先给你定 3 条铁律（避免走弯路）

1. **不要先啃数学！** 数学是补漏用的，不是入门用的。先搞懂模型逻辑和流程，遇到不懂的数学再去补对应知识点，上来就啃高数线代 90% 会劝退。
2. **看课和写代码的比例必须 1:1**。AI 是工程学科，跑通 1 行代码，比背 100 个公式有用，每学一个知识点，必须动手写对应的代码验证。
3. **所有课程都按「对 C++ 部署有用」的标准学**。重点抓「前向计算流程、核心概念、工程逻辑」，直接跳过复杂的公式推导、训练调参技巧、学术冷门内容。

## 一、核心必学主课（按学习顺序，一步一步来）

### 模块 1：机器学习基础入门（先学这个，1-2 周搞定核心）

**目标**：搞懂 AI 最核心的概念、「训练 - 推理」的本质，吃透线性回归、逻辑回归这些基础模型，为深度学习打地基。

#### 首选推荐：吴恩达《机器学习 2022 新版》（全网新手入门天花板）

- 观看渠道：B 站搜「吴恩达 机器学习 2022」，有完整中英字幕免费版

- 适配性：完全 0 基础友好，用生活案例讲透原理，几乎没有生硬的公式堆砌，全球公认的 AI 入门第一课

- ✅ 重点必学章节（只看这些就够了）：

  1. 第一周：机器学习核心概念、监督 / 无监督学习的区别、线性回归模型（核心中的核心）、代价函数、梯度下降的**直观理解**（不用抠公式推导，懂它是干嘛的就行）
  2. 第二周：逻辑回归（分类任务的基础，必学）、回归与分类的核心区别
  3. 选看：第三周的「决策树核心逻辑」「过拟合 / 欠拟合的概念」（知道是什么就行，不用抠细节）

- ❌ 直接跳过的内容：

  所有复杂的数学求导推导、多变量线性回归的矩阵公式、正则化的公式证明、优化器的细节、Python 编程作业（可以简单跑一下，不用花大量时间打磨，重点是理解逻辑）

#### 中文平替（怕英文不习惯）：B 站 白板编程《机器学习入门 - 西瓜书陪读》

- 观看渠道：B 站免费
- 适配性：对着周志华《西瓜书》讲解，完全避开复杂公式，只讲核心逻辑和通俗理解，适合怕英文、想快速抓重点的新手
- 重点看：线性回归、逻辑回归、决策树的核心逻辑章节，其他全部跳过

------

### 模块 2：深度学习核心入门（机器学习基础看完再学，2-3 周搞定核心）

**目标**：搞懂 CNN、Transformer 这两个工业界 90% 场景都会用到的模型结构，吃透前向传播的完整计算流程 —— 这是你后续做 C++ 部署的核心基础。

#### 首选推荐：李沐《动手学深度学习 PyTorch 版》

- 观看渠道：B 站搜「李沐 动手学深度学习」，配套官网 d2l.ai，完全免费

- 适配性：既有原理讲解，又有代码演示，会讲「这个东西在工业界怎么用」，不搞纯学术，是最贴合工程落地的深度学习入门课

- ✅ 重点必学章节（只看这些就够了）：

  1. 深度学习基础：多层感知机 MLP、前向 / 反向传播的直观逻辑、激活函数的作用（不用抠反向求导）
  2. 重中之重：卷积神经网络 CNN（核心！）—— 卷积层、池化层的计算过程、特征图维度变化、经典 CNN 模型（LeNet/AlexNet）的结构，这是视觉 AI 部署的核心
  3. 必学：Transformer 基础结构 —— 自注意力机制、Encoder/Decoder 的核心逻辑、前向传播的计算流程（现在大模型、视觉、语音都用 Transformer，必须懂基础结构）

- ❌ 直接跳过的内容：

  反向传播的公式推导、训练调参技巧、优化器的细节、冷门模型结构、竞赛实战、复杂的 Python 训练代码（你只需要关注「模型结构、前向计算逻辑」，不用学怎么训练调参）

#### 入门友好平替：B 站 王鹤麟《深度学习详解》

- 观看渠道：B 站免费
- 适配性：完全从 0 开始，大白话讲解，公式极少，先讲「为什么要这么设计」，再讲「是什么」，对新手极度友好，尤其是 CNN、Transformer 的部分，讲得非常通透
- 重点看：CNN 卷积神经网络全章、Transformer 全章，其他按需看

## 二、辅助补漏课（按需学，不要先学，遇到不懂的再补）

### 模块 1：数学基础补漏（绝对不要先啃！遇到不懂的再补对应知识点）

很多新手入门先学半年数学，直接劝退，完全没必要。你只需要在遇到不懂的数学概念时，再去补对应的知识点就行。

#### 1. 线性代数必看：B 站 3Blue1Brown《线性代数的本质》

- 观看渠道：B 站免费
- 适配性：完全不讲做题考试，用动画讲透线性代数的核心意义，比如矩阵乘法到底是干嘛的、向量和张量的关系，看完你会对 AI 里的矩阵运算豁然开朗
- 重点看：向量、矩阵乘法、线性变换这几集，其他按需看

#### 2. 概率论补漏：B 站 宋浩《概率论与数理统计》（精简版）

- 观看渠道：B 站免费
- 适配性：大学标准课程，讲得细致易懂，你只需要补「随机变量、基础概率分布、期望、方差」这些核心概念就行，其他完全不用看

### 模块 2：C++ 高性能计算补漏（做项目优化时再学）

#### 2. CUDA 编程入门：B 站 赵文杰《CUDA 编程入门与实战》

- 适配性：从 0 开始讲 CUDA C++ 编程，适合新手入门，教你用 GPU 做并行计算，对接 TensorRT 的自定义算子优化，是中高端 AI 工程岗的必备技能

## 四、避坑红线（一定要记住）

1. 不要收藏一堆课就不看了，就按上面的顺序，一个一个来，先把吴恩达的核心章节看完、代码跑通，再往下走
2. 不要跑偏去学 Python 炼丹、调参、刷竞赛，你的核心优势是 C++，所有学习都要围绕「怎么用 C++ 把 AI 模型跑起来、跑快」

4. 学校的人工智能理论课，就按这个重点去听，考试内容应付就行，不用为了卷绩拼死抠学术推导

- **目标**：吃透「神经网络前向计算流程」—— 这是你之后用 C++ 写模型推理的核心能力，直接对接部署工作
