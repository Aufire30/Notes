# 类

类是"对象的模板"，把数据和操作数据的方法打包在一起。`__init__` 是初始化方法，`self` 指代实例本身：

```python
class Student:
    
    def __init__(self,name,score):
        self.name = name
        self.score = score

    def Print(self):
        print(f"{self.name} 考了 {self.score} 分")


s1 = Student("小明",95)
s1.Print()
```

- “创建实例时自动执行”的初始化方法，必须叫 `__init__`
- Python 会**自动将当前对象实例作为第一个参数**传入该方法，所以函数的self是一定要写的
