# Numpy

NumPy 是 Python 做数值计算的核心库，核心数据结构是 **ndarray（多维数组）**，比 Python 列表快得多，支持"向量化运算"（一次对整个数组操作，不用写循环）。

```python
import numpy as np

# 创建数组
a = np.array([1, 2, 3, 4])
print(a)              # [1 2 3 4]

# 形状：几行几列
m = np.array([[1, 2], [3, 4]])
print(m.shape)        # (2, 2)，2 行 2 列

# 向量化运算：一次作用于每个元素
print(a * 2)          # [2 4 6 8]
print(a + 10)         # [11 12 13 14]

# 索引与切片（和列表类似）
print(a[0])           # 1，第一个元素
print(a[1:3])         # [2 3]，切片，左闭右开

# 常用创建函数
zeros = np.zeros(3)        # [0. 0. 0.]
ones = np.ones((2, 2))     # 2x2 全 1 矩阵
rng = np.arange(0, 10, 2)  # [0 2 4 6 8]，类似 range
```
