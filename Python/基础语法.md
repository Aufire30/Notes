# 快读模板

```python
import sys
input = lambda:sys.stdin.readline().strip()
```

**通过重写内置 `input()` 函数，利用底层 `sys.stdin.readline()` 实现远超原生 `input()` 的读取速度**，同时清理首尾空白字符

当数据量达到**万级 / 十万级**行时，`sys.stdin.readline()` 比 `input()` 快 **3-5 倍**，能有效避免**超时（Time Limit Exceeded）** 问题。

# 输入

## 单行多个整数

```python
a,b,c = map(int,input().split()) #输入:1 2 3
print(a,b,c) #输出:1 2 3
```

`map()` 是 Python 内置的**高阶函数**，核心功能是：**把一个函数，批量作用到一个可迭代对象（比如列表、字符串、`split()` 生成的序列）的每一个元素上，返回一个新的迭代器**。

`.split()` 按空格分割，生成一个字符串列表 `['1', '2', '3']`（这是一个可迭代对象）

`int`将每个字符转换成int类型，得到一个迭代器，里面是 `[1, 2, 3]` 对应的整数对象

把迭代器里的 3 个整数，分别解包赋值给变量 `a`、`b`、`c`

## 多行多个整数

```python
n = int(input()) #输入行数
lst = [int(input()) for _ in range(n)] #读取n行整数
print(lst)
```

- `range(n)`：生成一个从 `0` 到 `n-1` 的整数序列，循环 `n` 次。

  `int(input())`：在每次循环中，**读取一行输入并转为整数**。

  `[...]`：把每次循环读取的结果收集起来，生成一个最终的**列表**。

# 双端队列

![image-20260401084629818](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260401084629818.png)

> **竞赛应用场景**
>
> **队列**：**BFS**层序遍历、滑动窗口等
>
> **栈**：**DFS**路径回溯、括号匹配、单调栈优化

## 队列

```python
from collections import deque

q = deque #初始化
q.append(x) #从右侧入队
q.appendleft(x) #从左侧入队(特殊情景)
x = q.popleft() #从左侧出队(时间复杂度O(1))
len(q) #获取队列长度
```

## 栈

```python
stk = [] #用队列模拟
stk.append(x) #入栈
x = stk.pop	#出栈(默认弹出最后一个元素，时间复杂度O(1))
stk[-1] #获取栈顶元素(不移除)
```

## 实用技巧

```python
if not q #快速判断空队列/栈
stack[::-1] #栈的翻转(用切片获取逆序)
```
