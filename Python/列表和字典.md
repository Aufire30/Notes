# 列表

```python
# 列表 list：有序、可修改，用下标访问
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[0])        # 苹果（下标从 0 开始）
fruits.append("西瓜")   # 末尾添加
print(len(fruits))      # 4
```



# 字典

```python
# 字典 dict：键值对，用 key 查找
student = {"name": "小刚", "age": 20}
print(student["name"])      # 小刚
student["city"] = "上海"    # 新增键值对
```
