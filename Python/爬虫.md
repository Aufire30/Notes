## 创建爬虫

> 爬取豆瓣top250

1.scrapy startproject 项目名	**创建项目**

2.scrapy genspider 爬虫名 域名 **创建爬虫**

3.scrapy crawl 爬虫名 (--nolog 删除日志) 	**运行爬虫**

4.在 Scrapy 的 parse 方法中，通常使用 yield 而不是 return：

- return 是退出整个函数
- yield 产生一个结果，但循环继续执行
