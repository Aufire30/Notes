# 埃氏筛

> 求小于等于 n 的所有**质数**(素数)，时间复杂度O(nloglogn)
>
> `质数（素数）`的严格定义是：**大于 1 的自然数，除了 1 和它本身之外，没有其他正因数**。

![image-20260401090646194](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260401090646194.png)

> **每次遇到一个质数(素数),就往后把它的倍数划去**

```python
primes = [] #存取素数
is_prime = [True] *(n + 1) #最大为可能遇到的质数 + 1
is_prime[1] = is_prime[0] = False #将0和1排除，因为外层循环是从2开始的

for i in range(2,int(math.sqrt(n)) + 1): #i * i <= n
    if is_prime[i]:
        for j in range(i * i,n + 1,i):
            is_prime[j] = False #划去遇到的质数的倍数
for i in range(2,n + 1):
    if is_prime[i]:primes.append(i)
```

# 逆波兰表达式

> 也称**后缀表达式**
>
> 所有操作符置于操作数后面，不需要括号来标识操作符的优先级

![image-20260401092139197](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260401092139197.png)

```python
def eval_rpn(tokens:list[str]) -> int:
    stack = []
    ops = {
        '+':lambda a, b: a + b,
        '-':lambda a, b: a - b,
        '*':lambda a, b: a * b,
        '/':lambda a, b: int(a / b) #这里是向零取整，而非python默认的向下取整
    }

#如果是操作符且是ops里面的其中一个，将操作数全部弹出并计算后再入栈，如果不是操作符是操作数就直接入栈
for t in tokens:
    if t in ops:		
        b = stack.pop()
        a = stack.pop()
        stack.append(ops[t](a,b)) #a在前，b在后
    else:
        stack.append(int(t))
return stack[0]
```

# 贪心算法

> 每一步都选**当下最好**的，
>
> 最后整体结果也**最好**

例题：训练士兵

> ![image-20260401203004812](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260401203004812.png)

```python
import os
import sys

# 请在此输入您的代码
n,S = map(int,input().split())
jinbi = [] #存储每个士兵的 (p_i, c_i) 信息
tot = 0 #当前所有「还需要补训练」的士兵的 p_i 之和
ans = 0 #最终的最小总花费
cnt = 0 #已经完成的组团训练总次数

for _ in range(n):
  p,c = map(int,input().split())
  jinbi.append((p,c))
  tot += p

#按士兵需要的总训练次数 c_i 从小到大排序
jinbi.sort(key = lambda x : x[1]) #让列表按照每个元素的第 2 个值进行升序排序

for i in range(n):
  if tot >= S: #组团
    ans += (jinbi[i][1] - cnt) * S  #本来需要的训练次数减去已经完成的组团训练次数
    cnt = jinbi[i][1]#jinbi[i][1]即取出第i个士兵的第二关元素，就是该士兵需要的训练次数
  else: #单独
    ans += (jinbi[i][1] - cnt) * jinbi[i][0]
  
  tot -= jinbi[i][0]

print(ans)
```

```python
class Solution:
    def reconstructQueue(self, people: List[List[int]]) -> List[List[int]]:
        people.sort(key = lambda x :(-x[0],x[1])) #身高按降序排序，人数按升序排序
        res = []
        for i,p in enumerate(people): #i得到的是索引，p即索引对应的people里面的元素
            h,k = p[0],p[1] #h为元素的第一个数值(即身高)，k为第二个数值(即人数)
            if k == i: #如果人数和索引相等，则直接依次入栈
                res.append(p)
            elif k < i: #如果人数小于索引，说明应该往前插入
                res.insert(k,p)
    
        return res
```

# 二分查找

> 仅适用于**有序数组**，最坏情况下需要 ⌊log2n⌋+1 次比较，时间复杂度为为 O(logn)

- 基本模型：给定一个单调不**减**的数组a，返回恰好**严格大于**x的**下标**位置

​		   给定一个单调不减的数组a，返回第一个**严格大于**x的**下标**位置

​		   给定一个单调不减的数组a，返回恰好**a[i] > x**的**下标**位置

​	记为**bisect(a,x)**

> ![image-20260407171658797](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260407171658797.png)

- 变形1：给定一个单调不**减**的数组a，返回恰好**大于等于x**的下标位置

​							   (返回恰好**大于x - 1**的下标位置)

​	记为**bisect(a,x - 1)**

> ![image-20260407172037396](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260407172037396.png)

- 变形2：给定一个单调不**减**的数组a，返回恰好**小于等于x**的下标位置

  ​							      (返回恰好**大于x**的**下标位置 - 1**)

  记为**bisect(a,x) - 1**

## 朴素二分

> 二分查找的底层实现

```python
def bisect(a,x, lo = 0,hi = None):
    if hi is None:hi = len(a)
    while lo < hi:
        i = (lo + hi) >> 1 #i = (lo + hi)/2
        if a[i] > x:
			hi = i
        else:
            lo = i + 1
    return lo
```

**`(lo + hi) >> 1`**：是**位运算**，对整数二进制右移一位，结果**永远是整数**。

- 例如：`(3+4) >> 1 = 7 >> 1 = 3`（整数）。

**`(lo + hi) / 2`**：是**浮点除法**，结果**必然是浮点数**。

- 例如：`(3+4) / 2 = 3.5`。



**支持传递check函数**

```python
def bisect(a,x, lo = 0,hi = None,check = lambda y:y):
    if hi is None:hi = len(a)
    while lo < hi:
        i = (lo + hi) >> 1 #i = (lo + hi)/2
        if check(a[i]) > x:
			hi = i
        else:
            lo = i + 1
    return lo

print(bisect(a,x,check = lambda y:y ** 3 + y * 2 + 1))
```

# 二分答案

> 与二分查找的区别：
>
> 二分查找：在一个已知的有序数据集上进行二分查找
>
> 二分答案：答案有一个连续区间，在这个区间上二分，直接找到最优答案

**一般满足条件**：

- 求最值/最优问题
- 答案res存在一个确定、连续区间[lo,hi]
- 对确定的res = i，能够求出check(i) = False还是True,即是否满足条件
- 有一定单调性，随着单调的过程，会有False->True或True->False的过程

例题：

![image-20260408091237013](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20260408091237013.png)

```python
class Solution:
    def maximumCandies(self, candies: List[int], k: int) -> int:
        # 边界情况：总糖果数 < k，连每人1颗都分不到，直接返回0
        if sum(candies) < k:
            return 0
        
        # 二分查找的左右边界：
        # lo = 1（最小可能分1颗），hi = max(candies) + 1（最大可能分max(candies)颗，+1是为了开区间）
        lo, hi = 1, max(candies) + 1
        
        # 验证函数：判断「每人分res颗」是否可行
        def check(res):
            # 计算所有堆能分出多少个res颗的子堆，总和 < k 说明不够分
            return sum(x // res for x in candies) < k
        
        # 二分查找主循环（开区间写法：[lo, hi)）
        while lo < hi:
            # 取中间值（等价于 (lo+hi)//2，位运算更高效）
            i = (lo + hi) >> 1
            if check(i):
                # 分i颗不够，说明要缩小右边界，即减少分的颗数i，在[lo, i)里找
                hi = i
            else:
                # 分i颗够，说明可以尝试更大的数，在[i+1, hi)里找
                lo = i + 1
        
        # 循环结束时lo是第一个「不够分」的数，所以最大可行数是lo-1
        return lo - 1
```
