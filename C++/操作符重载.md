# “+”操作符重载

```cpp
example operator+ (const example& other) const
{
	return example(a + other.a, b + other.b);
}
```

或者如果项目涉及**导出 API、脚本绑定**或**团队规范倾向于显示函数名**，使用

```cpp
example Add(const example& other)
{
	return example(a + other.a, b + other.b);
}
example operator+ (const example& other)
{
	return Add(other);
}
```

> 其他运算符重载类似



**C++ 标准库惯用写法（Idiomatic C++）：** 在标准 C++ 实践中，通常推荐先实现 **`operator+=`**，然后利用 `operator+=` 来实现自由函数（非成员函数）形式的 **`operator+`**。例如：

```cpp
// 成员函数：复合赋值运算符
example& operator+=(const example& other) {
    this->a += other.a;
    this->b += other.b;
    return *this;
}

// 非成员函数：加法运算符（允许左操作数发生隐式类型转换）
example operator+(example lhs, const example& rhs) {
    lhs += rhs;
    return lhs;
}
```

# 输入输出流

输出`<<`

**在类外定义**

```cpp
std::ostream& operator<< (std::ostream& stream,const example& other)
{
	stream << other.a << " " << other.b;
	return stream;
}
```

输入`>>`

```cpp
std::istream& operator>> (std::istream& stream, example& other)
{
    stream >> other.a >> other.b;
    return stream;
}
```





如果 `a` 和 `b` 是类中的私有成员（`private`），需要将流重载函数声明为类的**友元函数（`friend`）**：

```cpp
#include <iostream>

class example {
private:
    int a;
    int b;

public:
    example(int a = 0, int b = 0) : a(a), b(b) {}

    // 输出流重载 (<<)
    friend std::ostream& operator<<(std::ostream& stream, const example& other) {
        stream << other.a << " " << other.b;
        return stream;
    }

    // 输入流重载 (>>)
    friend std::istream& operator>>(std::istream& stream, example& other) {
        stream >> other.a >> other.b;
        return stream;
    }
};

int main() {
    example obj;
    
    std::cout << "请输入两个整数：";
    std::cin >> obj;       // 调用 operator>>
    
    std::cout << "输入的结果为：" << obj << std::endl; // 调用 operator<<
    return 0;
}
```
