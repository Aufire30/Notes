# 三元运算符

> 为了简化if-else语句，可以用三元运算符

```cpp
int speed = 5;
std::string level;
    
if(speed > 10)
{
	level = "Master";
}
else
{
	level = "Beginer";
}
```

if-else语句变成三元运算符就是

```cpp
level = speed > 10 ? "Master" : "Beginer";
```



还有另一种使用方法

```cpp
level = speed > 5 ? speed > 10 ? "Top" : "Master" : "Beginer";
```

- <= 5 		 “Beginer”;
- \> 5 && <= 10  “Master”;
- \> 10                  “Top”;



还可以为每个条件添加额外的条件(**&& speed < 100**)

```cpp
level = speed > 5 && speed < 100 ? speed > 10 ? "Top" : "Master" : "Beginer";
```
