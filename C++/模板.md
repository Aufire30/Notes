# 函数模板

```cpp
#include<iostream>

template<typename T>

void Print(T var)
{
	std::cout << var << std::endl;
}
int main()
{
	Print(5);
	Print("qin");
	Print(5.5f);

	std::cin.get();
}
```

- 现代 C++ 规范更推荐统一使用 `typename`，因为这样能直观地表达 **“`T` 可以是包括 `int`、`float` 在内的任何数据类型，而不局限于类 (`class`)”**。

- 调用函数模板的时候，会**自动推导**参数的类型

- 函数模板在没有被调用的时候，不会被创建出来占用内存，只用调用的时候才会被创建



# 类模板

## 非类型模板参数

如果模板参数传入的**不是一个类型，而是一个具体的数值/常量**，则不需要使用 `typename`，直接写数据类型即可：

```cpp
template<int N>
class Array
{
private:
	int m_Array[N];
public:
	int GetArraySize()const { return N; };
};
int main()
{
	Array<5> arr;
	std::cout << arr.GetArraySize() << std::endl;
	std::cin.get();
}
```

## 多模板参数

```cpp
#include<iostream>
template<typename T,int N>

class Array
{
private:
	T m_Array[N];
public:
	int GetArraySize()const { return N; };
};
int main()
{
	Array<int,5> arr;
	std::cout << arr.GetArraySize() << std::endl;
	std::cin.get();
}
```

T表示类型，N表示大小
