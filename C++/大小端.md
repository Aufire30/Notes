**大端（Big-Endian）** 和 **小端（Little-Endian）** 是计算机在内存中**存储多字节数据（如 int, short, float）时的字节排列顺序（字节序 Byte Order）**。

---

### 1. 通俗易懂的例子

假设有一个 4 字节的整数 `int x = 0x12345678;`：
* 高位字节（最高有效位）：`12`
* 低位字节（最低有效位）：`78`

如果要把这个数存入从地址 `0x100` 开始的内存中，两种模式的存放顺序如下：

| 内存地址             | **小端模式 (Little-Endian)** | **大端模式 (Big-Endian)** |
| :------------------- | :--------------------------- | :------------------------ |
| `0x100` **(低地址)** | **`78`** (低位字节)          | **`12`** (高位字节)       |
| `0x101`              | `56`                         | `34`                      |
| `0x102`              | `34`                         | `56`                      |
| `0x103` **(高地址)** | **`12`** (高位字节)          | **`78`** (低位字节)       |

> [!IMPORTANT]
>
> **小端（Little-Endian）**：**低**位字节存放在**低**内存地址。（**小对小，低对低**）
>
> **大端（Big-Endian）**：**高**位字节存放在**低**内存地址。（符合人类从左往右的阅读习惯）

---

### 2. 它们各用在什么地方？

#### 💻 小端模式（最常见）：
* **PC 电脑**：Intel / AMD 的 x86 和 x64 架构芯片（Windows / Linux 电脑）。
* **移动设备**：大部分 ARM 芯片（如 iPhone、Android 手机）。
* **特点**：对于计算机的加法运算器，先处理低位再处理高位效率更高，因此**现代 CPU 绝大多数都是小端模式**。
* **现象**：这就是为什么刚才你在 Visual Studio 的内存窗口中查看数据时，发现内存里的十六进制字节是**倒着排序**的原因！

#### 🌐 大端模式：
* **网络传输**：TCP/IP 协议规定所有网络数据传输必须使用大端模式（因此大端又被称为**网络字节序 Network Byte Order**）。
* 部分老式服务器、大型机（如 IBM PowerPC）。

---

### 3. C++ 中如何用代码判断是大端还是小端？

在 C++ 中利用**指针强制类型转换**来检测当前系统是哪种模式：

```cpp
#include <iostream>

int main() {
    unsigned int a = 0x12345678;
    // 取 a 的首地址，转成 char* 类型的指针（只看第 1 个字节）
    unsigned char* p = (unsigned char*)&a;

    if (*p == 0x78) {
        std::cout << "当前系统是：小端模式 (Little-Endian)" << std::endl;
    } else if (*p == 0x12) {
        std::cout << "当前系统是：大端模式 (Big-Endian)" << std::endl;
    }

    return 0;
}
```

在 C++20 中，标准库提供了更直观的判断方法（需要包含 `<bit>`）：
```cpp
#include <bit>
#include <iostream>

if (std::endian::native == std::endian::little) {
    std::cout << "小端模式";
}
```
