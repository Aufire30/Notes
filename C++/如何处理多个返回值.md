在 C++ 中，函数本身只能有一个 `return` 值。但实际开发中经常需要返回多个数据，现代 C++（尤其是 C++17 及以后）提供了非常优雅的处理方式。

以下是 **5 种最常用的处理多个返回值的方法**，按现代 C++ 推荐程度从高到低排序：

---

### 方法 1：使用 `struct` 自定义结构体（最推荐：语义最清晰）
当你返回的多个数据有明确的业务含义时，**定义一个简单的 `struct` 是最佳实践**。

```cpp
#include <iostream>
#include <string>

// 1. 定义结构体
struct UserInfo {
    int id;
    std::string name;
    double score;
};

// 2. 函数返回结构体
UserInfo getUser() {
    return {1001, "Alice", 95.5}; // C++11 初始化列表语法
}

int main() {
    // 方式 A：标准访问
    UserInfo user = getUser();
    std::cout << user.name << " 的分数是: " << user.score << "\n";

    // 方式 B：C++17 结构化绑定（Structured Binding），直接拆解变量
    auto [id, name, score] = getUser();
    std::cout << name << " 的 ID 是: " << id << "\n";
}
```
* **优点**：每个字段都有明确名字（`name`、`score`），代码可读性极高。

---

### 方法 2：使用 `std::tuple` 元组（C++11/17：适合快捷组合）
如果你不想专门为了一个函数去定义 `struct`，可以用标准库的元组 `std::tuple`。

```cpp
#include <iostream>
#include <tuple>
#include <string>

// 返回 int, string, double
std::tuple<int, std::string, double> getUserData() {
    return {1002, "Bob", 88.0};
}

int main() {
    // 接收方式：利用 C++17 结构化绑定解包（强烈推荐）
    auto [id, name, score] = getUserData();
    std::cout << name << ": " << score << "\n";

    // C++11/14 传统写法（用 std::get<N>，可读性稍差）
    auto data = getUserData();
    int id2 = std::get<0>(data);
    std::string name2 = std::get<1>(data);
}
```
* **优点**：无需预先定义 `struct`，临时随用随写。
* **缺点**：如果没有结构化绑定，`std::get<0>` 可读性不如结构体的成员变量名。

---

### 方法 3：使用 `std::pair`（适合**恰好只有 2 个**返回值）
如果**正好只有 2 个**返回值，标准库提供了更轻量的 `std::pair`。

```cpp
#include <iostream>
#include <utility> // 包含 std::pair

// 比如判断是否成功，并返回结果
std::pair<bool, std::string> login(const std::string& username) {
    if (username == "admin") {
        return {true, "登录成功"};
    }
    return {false, "密码错误"};
}

int main() {
    // C++17 解包
    auto [is_success, msg] = login("admin");
    if (is_success) {
        std::cout << msg << "\n";
    }

    // 传统写法：使用 .first 和 .second
    auto res = login("guest");
    std::cout << res.first << ", " << res.second << "\n";
}
```

---

### 方法 4：使用引用参数 / 出参（Output Parameters，传统写法）
在 C++11 之前，最普遍的做法是将接收变量以非 const 引用的方式传入函数。

```cpp
#include <iostream>
#include <string>

// 通过引用参数输出
bool getUserInfo(int input_id, std::string& out_name, double& out_score) {
    if (input_id == 1) {
        out_name = "Charlie";
        out_score = 90.0;
        return true;
    }
    return false;
}

int main() {
    std::string name;
    double score;
    
    // 缺点：必须先在外部定义变量
    if (getUserInfo(1, name, score)) {
        std::cout << name << ": " << score << "\n";
    }
}
```
* **缺点**：需要在外部提前声明变量，破坏了函数调用的流畅度（不如 `auto val = func()` 干净）。

---

### 方法 5：使用 `std::optional`（适合“数据 + 是否成功”）
如果“多个返回值”的目的是**返回数据的同时告知调用者操作是否成功**，C++17 引入的 `std::optional` 是最佳选择：

```cpp
#include <iostream>
#include <optional>

// 如果找不到返回 std::nullopt，找到则返回具体值
std::optional<double> getScore(int student_id) {
    if (student_id == 101) {
        return 99.5; // 有值
    }
    return std::nullopt; // 无值（代表未找到）
}

int main() {
    auto score = getScore(101);
    if (score.has_value()) { // 或直接写 if (score)
        std::cout << "成绩: " << score.value() << "\n";
    } else {
        std::cout << "学生不存在\n";
    }
}
```

---

### 💡 选型总结

| 场景                             | 推荐方式                       | 示例语法                             |
| :------------------------------- | :----------------------------- | :----------------------------------- |
| **字段含义明确（如用户、坐标）** | **定义 `struct` + 结构化绑定** | `auto [x, y, z] = getPoint();`       |
| **临时快捷返回 3 个及以上数据**  | **`std::tuple` + 结构化绑定**  | `auto [a, b, c] = getThreeValues();` |
| **恰好 2 个返回值**              | **`std::pair` + 结构化绑定**   | `auto [ok, msg] = checkStatus();`    |
| **“返回值 + 是否成功/存在”**     | **`std::optional<T>`**         | `auto res = findItem();`             |
| **需要与 C 语言接口/旧代码兼容** | **引用/指针出参**              | `func(&out1, &out2);`                |
