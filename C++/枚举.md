# 枚举

```cpp
enum Example
{
	A, B, C
};

int main()
{
	Example value = A;
	if (value == A)
	{
		std::cout << value << std::endl;
	}
	return 0;
}
```

枚举中，如果没有初始化，默认从0开始，每次递增1，即A = 0,B = 1,C = 2;

```cpp
enum Example
{
	A = 5, B, C
};
```

也可以从5开始递增1

```cpp
enum Example
{
	A = 5, B = 6, C = 7
};
```

或全部初始化





可以指定枚举值的数据类型

```cpp
enum Example ： int
{
	A,B,C
};
```

通过冒号+数据类型来指定

| 数据类型类别     | 支持的具体类型                                             | 说明                                         |
| :--------------- | :--------------------------------------------------------- | :------------------------------------------- |
| **基础整型**     | `char`, `signed char`, `unsigned char`                     | 占用 1 字节                                  |
| **短整型**       | `short`, `unsigned short`                                  | 占用 2 字节                                  |
| **标准整型**     | `int`, `unsigned int`                                      | **默认类型**（如果不显式指定，默认是 `int`） |
| **长整型**       | `long`, `unsigned long`, `long long`, `unsigned long long` | 占用 4 或 8 字节（用于很大数值的枚举）       |
| **标准定宽整型** | `uint8_t`, `int16_t`, `uint32_t`, `int64_t` 等             | 适合网络传输、硬件编程或跨平台网络协议       |
| **布尔型**       | `bool`                                                     | 语法上允许，但极少使用                       |

以下类型**绝对不能**作为枚举的底层类型：

- ❌ **浮点数**：`float`, `double` （如 `enum { A = 1.5 };` 语法不合法）
- ❌ **字符串**：`const char*`, `std::string` （如 `enum { A = "Hello" };` 不支持）
- ❌ **指针 / 数组 / 结构体**：如 `int*`, `struct` 等
