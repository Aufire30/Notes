# 虚函数

> ##### 平常写代码的时候会发生想调用子类的方法缺调用到了父类的方法的情况

```cpp
#include<iostream>
class Entity
{
public:
	std::string GetName()
	{
		return "Entity";
	}
};

class Player : public Entity
{
private:
	std::string p_Name;
public:
	Player(const char* name)
		:p_Name(name)
	{}

	std::string GetName()
	{
		return p_Name;
	}
};

void PrintName(Entity* entity)//传入的是Entity类的参数，就去Entity类里面寻找需要的方法(GetName)
{
	std::cout << entity->GetName() << std::endl;
}

int main()
{
	Entity* e = new Entity();
	PrintName(e);//Entity

	Player* p = new Player("qinjinyan");
	PrintName(p);//Entity

	return 0;
}
```

> ##### 为了避免这种情况，就需要用到虚函数`virtual`

```cpp
class Entity
{
public:
	virtual std::string GetName()
	{
		return "Entity";
	}
};

class Player : public Entity
{
private:
	std::string p_Name;
public:
	Player(const char* name)
		:p_Name(name)
	{}

	std::string GetName() override
	{
		return p_Name;
	}
};
```



> ##### 虚函数并不是没有成本的，有两种虚函数运行时的花费
>
> - 一种是需要额外的内存来存储**虚表**，这样我们就可以分配到正确的函数，基类里还有一个指针成员指向虚表
> - 还有就是每次调用虚函数的时候，我们必须要遍历虚表去找到最终要运行的函数，这也是额外的损失



# 纯虚函数

> 纯虚函数允许我们定义一个在基类中没有实现的函数，然后强制子类去实现这个函数

```cpp
class Entity
{
public:
	virtual std::string GetName() = 0；
};
```

- 设置成纯虚函数后，则不再能**实例化**该类

- 只有纯虚函数被实现后，才能创造这个类的实例
- 如果想使用这个方法，就必须在子类中实现

```cpp
class Player : public Entity
{
private:
	std::string p_Name;
public:
	Player(const char* name)
		:p_Name(name)
	{}

	std::string GetName() override //实现
	{
		return p_Name;
	}
};
```
