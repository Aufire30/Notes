# 跟默认构造函数相比，为什么要用初始化列表？

**为什么需要初始化列表（优势与限制）**：

1. **性能更高**：直接调用成员的拷贝/移动构造函数。如果写在函数体内（`s = "hello";`），则是“先调用默认构造函数**生成空对象**，再调用赋值运算符 `operator=`”，**默认构造函数多了一步开销**。

2. 语法强制要求

   （以下三种情况必须使用初始化列表，不能在构造函数体内赋值）：

   - **`const` 成员变量**（必须在初始化时定值，不能二次赋值）。
   - **引用成员变量（`&`）**（引用必须在定义时绑定目标）。
   - **没有默认构造函数的类类型成员变量**。
