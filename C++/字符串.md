# 字符串

```cpp
const char* name = "qinjinyan";
name[2] = 'a';//报错，因为加上了const，常量无法修改
```

从C++11开始，常量强调加上const

其实在C++中使用双引号`“”`来定义一个字符串的时候，它就是一个const char*类型

```cpp
char name2[7] = {'j','i','n','y','a','n',0};//0表示空终止符，如果不加0，打印就不知道在哪里结束，就会打印随机字符
```

# string库

```cpp
#include<string>

std::string name = "Cheno";
std::cout << name << std::endl;
```

`<iostream>`其实上已经包括了`<string>`里面的内容，

但是如果要**打印字符串**，将字符串发送到输出流里面的话，还是需要`<string>`库，因为在string头文件中这个操作符**被重载实现了将字符串发送到输出流中**，否则会报错



- **获取字符串的长度**

```cpp
std::string name;
name.size();
```



```cpp
char* name;//如果是const char* 或者char*的话，就需要用到C语言的字符串操作
strlen(name);

strcpy//复制字符串
```

- **追加字符串**

```cpp
std::string name = "qinjinyan";
name += "hello!";
```

`+=`这个操作符在头文件string中被重载了

或者也可以这样写

```cpp
std::string name = std::string("qinjinyan") + "hello!"; //通过字符串构造函数
```

- **查找子字符串**

```cpp
name.find("qin");
```

find()返回的是这个子字符串的起始位置

# 宽字符

```cpp
const wchar_t* name = L"qinjinyan";
```

需要在字符串前面添加一个`L`来表示接下来的字符串是由宽字符组成的

宽字符**每个字符**都是**2字节**，但实际上还是又编译器来决定的，一般是2字节或4字节，windows上是2字节，linux上是4字节

**C++11还引入了其他类型**

```cpp
const char* name = u8"qinjinyan";

const char16_t* name1 = u"qinjinyan";

const char32_t* name2 = U"qinjinyan";
```

本质来说char就是1字节的字符

**char16是2字节**，**每个字符占16bit**，这就是**utf-16**

**char32是4字节，每个字符占32bit**，这就是**utf-32**

**const char***就是**utf -8**



# C++11 和 C++14 中关于“字符串字面量”（String Literals）的新特性与高级用法

## 1. 字符串后缀与 UTF-32 字符串拼接

```cpp
using namespace std::string_literals;

std::u32string name0 = U"Cherno"s + U" hello";
```

- **`U"..."`**：前缀 `U` 表示这是一个 **UTF-32** 编码的字符串字面量，类型为 `const char32_t[]`。
- **`s` 后缀**：属于 `std::string_literals` 命名空间（C++14 引入）。它能将字符串字面量直接转换为 `std::u32string` 对象，而不是原始指针 `const char32_t*`。
- **`+` 拼接**：因为 `U"Cherno"s` 变成了对象，所以可以直接使用 `+` 运算符与另一个字符串拼接。如果不加 `s`，两个 C 风格指针是无法直接用 `+` 相加的。

------

## 2. 原始字符串字面量（Raw String Literal）

```cpp
const char* example = R"(Line1
Line2
Line3
Line4)";
```

- **`R"(...)"`**：C++11 引入的**原始字符串字面量**。
- **作用**：括号内的所有内容都会按原样保留，**不需要写转义字符 `\n`**，直接换行就会在字符串中包含换行符。这在编写多行文本、正则表达式或嵌入 SQL/JSON 代码时非常方便。

------

## 3. 传统多行字符串写法（对比参考）

```cpp
const char* ex = "Line1\n"
                 "Line2\n"
                 "Line3\n";
```

- **对比**：这是 C/C++ 的传统写法。利用相邻字符串字面量会自动合并的特性，配合显式的 `\n` 换行符来实现多行字符串。
- 代码将两种方式放在一起，是为了对比 **原始字符串 `R"(...)"`** 比传统写法更直观、更易读。

------
