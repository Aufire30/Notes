# 数据读取-视频

- cv2.VideoCapture可以捕获摄像头，用数字来控制不同的设备，例如o,1。
- 如果是视频文件，直接指定好路径即可。

```python
vc = cv2.VideoCapture('test.mp4')
```

```python
# 检查是否成功打开
if vc.isOpened():
    open,frame = vc.read() #如果成功打开，返回open(一个布尔值)和frame(第一帧的图像矩阵图)
else:
    open = False
```

```python
while open:
    ret,frame = vc.read()
    if frame is None: #如果播放完了
        break
    if ret == True:
        gary = cv2.cvtColor(frame,cv2.COLOR_BGR2GRAY)
        cv2.imshow('result',gary)
        if cv2.waitKey(10) & 0xFF == 27:
            break

vc.release
cv2.destroyAllWindows()

```

### 1. `gary = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)`
* **含义**：将彩色图像转换成灰度图像。
* **细节**：
  * `cv2.cvtColor()` 是颜色空间转换函数。
  * `frame`：输入的单帧彩色图像（OpenCV 默认以 BGR 顺序存储）。
  * `cv2.COLOR_BGR2GRAY`：转换模式，表示由 BGR 彩色转为单通道灰度图。

### 2. `cv2.imshow('result', gary)`
* **含义**：在一个弹出窗口中显示灰度图像。
* **细节**：
  * `'result'`：显示窗口的标题名称。
  * `gary`：要在窗口中展示的灰度图像对象。

### 3. `if cv2.waitKey(10) & 0xFF == 27:`
* **含义**：**等待 10 毫秒，检测用户是否按下了键盘上的 `Esc` 键**。
* **细节**：
  * `cv2.waitKey(10)`：暂停等待 10 毫秒接收键盘输入。在视频播放中，这个时间也用来控制画面的帧率（如等待 10ms 即约 100fps）。
  * `& 0xFF`：按位与运算，确保在不同操作系统下只取按键返回值的后 8 位，得到标准的 ASCII 码。
  * `27`：键盘左上角 **`Esc` 键** 的 ASCII 码。

### 4. `break`
* **含义**：如果用户按下了 `Esc` 键，立即**跳出当前循环**（从而结束视频播放或关闭摄像头）。

# 在图像上写字(设置FPS显示)

```python
# 计算FPS
    prev_time = time.time()
    fps = 0.0

    while True:
        ret,frame = cap.read()
        if not ret:
            print("无法读取视频帧")
            return

        cur_time = time.time()
        time_diff = cur_time - prev_time
        prev_time = cur_time

        if time_diff > 0:
            instant_fps = 1.0 / time_diff
            # 指数平滑算法，避免数值快速剧烈抖动
            fps = 0.9 * fps + 0.1 * instant_fps if fps != 0.0 else instant_fps
```



```python
display_frame = frame.copy() 
fps_text = f"FPS:{fps:.1f}"
cv2.putText(display_frame, fps_text, (20, 40), 
                        cv2.FONT_HERSHEY_SIMPLEX, 0.9, (0, 255, 0), 2, cv2.LINE_AA)
```



| 参数               | 值                     | 含义                                                         |
| :----------------- | :--------------------- | :----------------------------------------------------------- |
| **目标图像**       | `display_frame`        | 要把文字绘制在哪张图上                                       |

| **起始位置坐标**   | `(20, 40)`             | **文字左下角**在图像上的坐标 `(x, y)`（距离左边缘 20px，距离顶部 40px） |

# 监听用户键盘输入

**监听用户的键盘输入，并获取所按下按键的 ASCII 码值**

```python
key = cv2.waitKey(1) & 0xFF
```

### 1. `cv2.waitKey(1)`

- **等待时长**：等待用户按键 `1` 毫秒。
- **刷屏必需**：在 OpenCV 中，`imshow` 必须配合 `waitKey` 才能正常渲染图像和处理 GUI 事件。
- 返回值：
  - 如果在 1ms 内**有键盘按下**，返回该按键的按键码（一个整数，如 ASCII 码）。
  - 如果在 1ms 内**无任何按键**，返回 `-1`。

------

### 2. `& 0xFF`（为什么需要按位与 `0xFF`？）

- **`0xFF` 的数值**：十六进制的 `0xFF` 等于二进制的 `11111111`（即十进制的 `255`）。
- 核心作用：跨平台兼容性与只保留低 8 位
  - 在 64 位系统或不同操作系统（Windows / Linux / macOS）上，`cv2.waitKey()` 返回的可能是一个 32 位的整数，有时还会附带键盘锁（如 NumLock / CapsLock）的状态高位。
  - `& 0xFF` 通过**位运算**遮罩，只保留最右边的 **低 8 位（一个字节）**，屏蔽高位修饰符干扰。这样可以确保在所有系统上得到的都是标准的 **ASCII 码**。

### 常见后续用法示例：

获取到 `key` 之后，通常会搭配分支语句进行操作（如退出或截图）：

```python
if key == ord('q'):
    # 按下 'q' 键退出循环
    break
elif key == ord('s'):
    # 按下 's' 键保存当前画面（截图）
    cv2.imwrite("screenshot.jpg", display_frame)
```

`ord()` 是 Python 的内置函数，全称是 **ordinal**（序数）。

它的作用是：**把单字符转换成对应的 Unicode / ASCII 整数值**。

```python
print(ord('a'))  # 输出: 97
print(ord('A'))  # 输出: 65
print(ord('q'))  # 输出: 113
print(ord('s'))  # 输出: 115
```

### 为什么在 OpenCV 里要用 `ord()`？

OpenCV 的 `cv2.waitKey()` 函数返回的是**整数（ASCII 码值）**，而不是字符串。

比如你按下了键盘上的 **q** 键：

- `cv2.waitKey(1) & 0xFF` 返回的是整数 **`113`**。
- 如果你写 `if key == 'q':` 会比较失败（整数 `113` 不等于字符串 `'q'`）。
- 使用 `ord('q')` 把 `'q'` 转换成整数 **`113`** 后，才能正确比对：
