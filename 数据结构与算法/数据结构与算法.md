# 栈

> **1.1栈的概念及结构**
> 栈：一种特殊的线性表，其只允许在**固定的一端**进行插入和删除元素操作。
> 进行数据插入和删除操作的一端称为栈顶，另一端称为栈底。栈中的数据元素遵守**后进先出**LIFO（Last In First Out）的原则。
>
> 压栈：栈的插入操作叫做进栈/压栈/入栈，**入数据在栈顶**。
>
> 出栈：栈的删除操作叫做出栈，**出数据也在栈顶**
>

> **链表：**
>
> ![image-20251004161340074](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20251004161340074.png)
>
> ```c
> typedef int DataType;
> 
> // 链栈节点结构
> typedef struct StackNode
> {
> 	DataType _data;
> 	struct StackNode* _next;
> }StackNode;
> 
> // 链栈结构
> typedef struct Stack
> {
> 	StackNode* _top;  // 栈顶指针
> 	int _size;        // 栈中元素个数
> }Stack;
> ```
>
> 
>
> ```c
> // 初始化
> void StackInit(Stack* pst)
> {
> 	assert(pst);
> 	pst->_top = NULL;
> 	pst->_size = 0;
> }
> 
> // 销毁
> void StackDestory(Stack* pst)
> {
> 	assert(pst);
> 	StackNode* cur = pst->_top;
> 	
> 	// 遍历链表，释放所有节点
> 	while (cur)
> 	{
> 		StackNode* next = cur->_next;
> 		free(cur);
> 		cur = next;
> 	}
> 	
> 	pst->_top = NULL;
> 	pst->_size = 0;
> }
> 
> // 入栈（头插）
> void StackPush(Stack* pst, DataType x)
> {
> 	assert(pst);
> 	
> 	// 创建新节点
> 	StackNode* newnode = (StackNode*)malloc(sizeof(StackNode));
> 	if (newnode == NULL)
> 	{
> 		printf("内存不足，入栈失败\n");
> 		exit(-1);
> 	}
> 	
> 	newnode->_data = x;
> 	newnode->_next = pst->_top;
> 	pst->_top = newnode;
> 	pst->_size++;
> }
> 
> // 出栈（头删）
> void StackPop(Stack* pst)
> {
> 	assert(pst);
> 	assert(pst->_top != NULL);  // 栈不能为空
> 	
> 	StackNode* next = pst->_top->_next;//保存要删除的节点的下一个节点
> 	free(pst->_top);
> 	pst->_top = next;
> 	pst->_size--;
> }
> 
> // 获取数据个数
> int StackSize(Stack* pst)
> {
> 	assert(pst);
> 	return pst->_size;
> }
> 
> // 返回1是空，返回0是非空
> int StackEmpty(Stack* pst)
> {
> 	assert(pst);
> 	return pst->_top == NULL ? 1 : 0;
> }
> 
> // 获取栈顶元素
> DataType StackTop(Stack* pst)
> {
> 	assert(pst);
> 	assert(pst->_top != NULL);  // 栈不能为空
> 	
> 	return pst->_top->_data;
> }
> ```

> **1.3栈的应用**
>
> - 迷宫问题：将**迷宫起点**压入栈中，并标记为已访问。
>
>   如果某个相邻格子是**通道且未被访问过**，则将其**压入栈中**，标记为已访问，作为新的当前位置。
>
>   **无路可走**则执行**出栈**操作。这一步至关重要，它意味着你**从死胡同退回到了上一个岔路口(一直出栈到上一个岔路口)**，栈顶变为上一个位置，从而可以尝试其他未走过的分支
>
> - 表达式求解：给出几个数字，求出能得到对应结果的多个表达式(加减乘除)
>
> - 递归改成非递归

# 队列

> **2.1队列的概念及结构**
>
> 队列：只允许**在一端进行插入**数据操作，**在另一端进行删除**数据操作的特殊线性表，队列具有**先进先出**FIFO(First In First Out)
> **入队列**：进行插入操作的一端称为**队尾**    
> **出队列**：进行删除操作的一端称为**队头**
> ![image-20251004194213535](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20251004194213535.png)
>
> **2.2队列的实现**
>
> 队列也可以**数组和链表**的结构实现，使用**链表的结构实现更优一些**，
>
> 因为如果使用数组的结构，出队列在数组头上出数据(**前移数据、队头下标移动**)，效率会比较低。
>
> **链表：**
>
> ```C
> //初始化
> void QueueInit(Queue* pq)
> {
> 	assert(pq);
> 	pq->_head = pq->_tail = NULL;
> }
> 
> //销毁
> void QueueDestory(Queue* pq)
> {
> 	assert(pq);
> 	QueueNode* cur = pq->_head;
> 	while (cur)
> 	{
> 		QueueNode* next = cur->_next;
> 		free(cur);
> 		cur = next;
> 	}
> 	pq->_head = pq->_tail = NULL;
> }
> 
> //入队
> void Queuepush(Queue* pq, DataType x)
> {
> 	assert(pq);
> 	QueueNode* newnode = (QueueNode*)malloc(sizeof(QueueNode));
> 	if (newnode == NULL)
> 	{
> 		printf("创建失败\n");
> 		exit(-1);
> 	}
> 	newnode->_data = x;
> 	newnode->_next = NULL;
> 
> 	if (pq->_head == NULL)
> 	{
> 		pq->_head = pq->_tail = newnode;//如果整个队列都是空，那么就插入一个新节点
> 	}
> 	else
> 	{
> 		pq->_tail->_next = newnode;//队列不为空那么就尾插
> 		pq->_tail = newnode;//更新尾节点
> 	}
> }
> 
> //出队
> void Queuepop(Queue* pq)
> {
> 	assert(pq);
> 	assert(pq->_head);//头节点不为空，如果为空就没得删了
> 
> 	QueueNode* next = pq->_head->_next;
> 	free(pq->_head);
> 	pq->_head = next;
> 
> 	if (pq->_head == NULL)//如果头节点删除移动到尾节点后面后
> 	{
> 		pq->_tail = NULL;//尾节点要置空，不然会变成野指针
> 	}
> }
> 
> //获取队头和队尾的数据
> DataType QueueFront(Queue* pq)
> {
> 	assert(pq);
> 	assert(pq->_head);
> 
> 	return pq->_head->_data;
> }
> DataType QueueBack(Queue* pq)
> {
> 	assert(pq);
> 	assert(pq->_tail);
> 
> 	return pq->_tail->_data;
> }
> 
> //判断队伍是否为空
> int QueueEmpty(Queue* pq)
> {
> 	assert(pq);
> 	return pq->_head == NULL ? 1 : 0;
> }
> 
> //获取队伍元素个数
> int QueueSize(Queue* pq)
> {
> 	assert(pq);
> 	QueueNode* cur = pq->_head;
> 	int size = 0;
> 	while (cur)
> 	{
> 		size++;
> 		cur = cur->_next;
> 	}
> 	return size;
> }
> ```
>
> **2.3队列的应用**
>
> - 先进先出的场景比如：保持序列公平：**排队抽号机**(如果队列为空，就入1号，下一次队列不为空，就去上一次队尾的数据加一 ，队列里面有多少人，就可以显示你前面还有**人，窗口叫人从队头选人，保证公平性，然后出队)

```C
{
    Stack st;

    bool ret;

            s++;
        }

    return ret;
```

1. **用队列实现栈** [OJ题](https://leetcode.cn/problems/implement-stack-using-queues/?clienttype=8&version=7.54.0.103&from=win32_yunguanjia&channel=00000000000000000000000040000001&privilege=&pri_extra=)

​	**用两个队列**，要**出数据**，就先把前面的数据转移到另一个空队列，把尾删除(实现**弹栈**)

​			       如果要**入数据**，那么就在非空的队列里面入数据(实现**压栈**)

```c
typedef struct 
{
    Queue _q1;
    Queue _q2;    
} MyStack;


MyStack* myStackCreate()//返回值是队列的结构体
{
    MyStack* st = (MyStack*)malloc(sizeof(MyStack));
    QueueInit(&st->_q1);
    QueueInit(&st->_q2);
    return st;
}

void myStackPush(MyStack* obj, int x) 
{
    if(!QueueEmpty(&obj->_q1))
    {
        Queuepush(&obj->_q1,x);
    }
    else
    {
        Queuepush(&obj->_q2,x);
    }
}

int myStackPop(MyStack* obj) 
{
    //先假设q1是空，q2非空
    Queue* empty = &obj->_q1;
    Queue* nonempty = &obj->_q2;
    if(QueueEmpty(&obj->_q2))
    {
        //如果q2是空，说明我们之前的假设是反的
        empty = &obj->_q2;
        nonempty = &obj->_q1;
    }
    while(QueueSize(nonempty) > 1)//直到非空里面只剩一个数据
    {
        //将非空的队头压栈到空队
        Queuepush(empty,QueueFront(nonempty));
        //压栈之后，原来非空的队头还存在，弹栈(删除)
        Queuepop(nonempty);
    }
    int top = QueueFront(nonempty);
    Queuepop(nonempty);//弹出最后一个数据(栈顶)
    return top;//返回栈顶元素 
}

int myStackTop(MyStack* obj) 
{
    if(!QueueEmpty(&obj->_q1))
    {
        return QueueBack(&obj->_q1);//q1不为空就获取q1的栈顶数据
    }
    else
    {
        return QueueBack(&obj->_q2);//q2不为空就获取q2的栈顶数据
    }
    //如果两个都为空就不会调用top函数
}

bool myStackEmpty(MyStack* obj)
{
    return QueueEmpty(&obj->_q1) && QueueEmpty(&obj->_q2);
}

void myStackFree(MyStack* obj) 
{
    QueueDestory(&obj->_q1);
    QueueDestory(&obj->_q2);

    free(obj);
}
```

​	用两个栈实现队列

​	**出队**：直接弹栈popST的栈顶

​	**入队**：入栈popST，如果popST为空才将pushST的元素压栈进popST

```C
typedef struct 
{
    Stack _pushST;
    Stack _popST;
} MyQueue;


MyQueue* myQueueCreate() 
{
    MyQueue* q = (MyQueue*)malloc(sizeof(MyQueue));
    StackInit(&q->_pushST);
    StackInit(&q->_popST);

    return q;
}

void myQueuePush(MyQueue* obj, int x) 
{
    StackPush(&obj->_pushST,x);
}

int myQueuePeek(MyQueue* obj)//即队的front函数
{
    if(!StackEmpty(&obj->_popST))
    {
        return StackTop(&obj->_popST);
    }
    else
    {
        while(!StackEmpty(&obj->_pushST))
        {
            //取pushST的栈顶元素压栈进popST
            StackPush(&obj->_popST,StackTop(&obj->_pushST));
            //压栈完后将pushST的栈顶元素pop，以便取到下一个
            StackPop(&obj->_pushST);
        }
        return StackTop(&obj->_popST);
    }
}

int myQueuePop(MyQueue* obj) 
{
    int front = myQueuePeek(obj);//获取popST的栈顶元素
    StackPop(&obj->_popST);//然后弹栈popST
    return front;
}

bool myQueueEmpty(MyQueue* obj) 
{
    return StackEmpty(&obj->_pushST) && StackEmpty(&obj->_popST);
}

void myQueueFree(MyQueue* obj) 
{
    StackDestory(&obj->_pushST);
    StackDestory(&obj->_popST);
    free(obj);

}
```

```C
typedef struct 
{
    int* _a;
    int _front;
    int _rear;
    int _k;
} MyCircularQueue;


MyCircularQueue* myCircularQueueCreate(int k) 
{
    MyCircularQueue* q = (MyCircularQueue*)malloc(sizeof(MyCircularQueue));
    q->_a = (int*)malloc(sizeof(int)*(k + 1));//多开一个，用于留空，避免空和满的判断错误
    q->_front = 0;
    q->_rear = 0;
    q->_k = k;
    
    return q;
}

bool myCircularQueueIsFull(MyCircularQueue* obj) 
{
    return (obj->_rear + 1) % (obj->_k + 1) == obj->_front;
}

bool myCircularQueueIsEmpty(MyCircularQueue* obj) 
{
    return obj->_front == obj->_rear; 
}

bool myCircularQueueEnQueue(MyCircularQueue* obj, int value) 
{
    if(myCircularQueueIsFull(obj))
        return false;
    obj->_a[obj->_rear] = value;//队尾插入一个数据
    obj->_rear++;
    obj->_rear %= (obj->_k+1);//防止超出范围，模等之后回到下标为0的位置 
    return true;
}

bool myCircularQueueDeQueue(MyCircularQueue* obj) 
{
    if(myCircularQueueIsEmpty(obj))
        return false;
    obj->_front++;
    obj->_front %= (obj->_k + 1);
    return true;
}

int myCircularQueueFront(MyCircularQueue* obj) 
{
    if(myCircularQueueIsEmpty(obj))
        return -1;
    else
    {
        return obj->_a[obj->_front];
    }
}   

int myCircularQueueRear(MyCircularQueue* obj) 
{
    if(myCircularQueueIsEmpty(obj))
    {
        return -1;
    }
    else
    {
        int rear = obj->_rear - 1;
        if(rear == -1)
        //此时的空格在第一个位置，rear指向它，要获取到队尾的数据，就返回下标为k的数据
        { 
            rear = obj->_k;
        }
        return obj->_a[rear];//rear会加到下一个位置，-1后才是队尾的数据
    }
}

void myCircularQueueFree(MyCircularQueue* obj) 
{
    free(obj->_a);
    free(obj);
}
```

>
>   合Ti(1<= i <= m)又是一棵结构与树类似的子树。**每棵子树的根结点有且只有一个前驱，可以**
>
>   **有0个或多个后继**
>
> - 树是**递归**定义的

## 二叉树概念及结构

> **2.1概念**
> 一棵二叉树是**结点的一个有限集合**，该集合或者**为空**，或者是**由一个根节点加上两棵别称为左子树和右子树的二叉树**组成。
>
> **二叉树的特点：**
>
> 1. 每个结点**最多有两棵子树**，即二叉树**不存在度大于2的结点**。
> 2. 二叉树的**子树有左右之分**，其**子树的次序不能颠倒**。
>
> **2.2特殊的二叉树：**
>
> 1. **满二叉树：**一个二叉树，如果**每一层的结点数都达到最大值**，则这个二叉树就是满二叉树。
>
>   也就是说，如果一个二叉树的**层数为K**，且**结点总数是(2^k) -1** ，则它就是**满二叉树**。
>
> 2. **完全二叉树：**完全二叉树是效率很高的数据结构，完全二叉树是由满二叉树而引出来的。对
>     于**深度为K**的，有**n个结点**的二叉树，当且仅当其每一个结点都与深度为K的满二叉树中**编号**
>     **从1至n的结点一一对应**(**从左到右依次编号、填满**)时称之为完全二叉树。 要注意的是**满二叉树是一种特殊的完全二叉**
>     **树**。
>
>   **完全二叉树**中**度为一的节点最多只有一个**
>
> ![image-20251020203150730](C:\Users\Aufire\AppData\Roaming\Typora\typora-user-images\image-20251020203150730.png)
>
> **2.3 二叉树的存储结构**
> 二叉树一般可以使用两种结构存储，一种**顺序结构**，一种**链式结构**。
>
> **二叉树的性质**
>
> 1. 若规定**根节点的层数为1**，则一棵非空二叉树的**第i层上最多有2^(i-1) 个结点**.
> 2. 若规定**根节点的层数为1**，则**深度为h的二叉树的最大结点数是2^h- 1**.
> 3. 对任何一棵二叉树, 如果**度为0**其**叶结点**个数为 **n0**, **度为2**的**分支结点**个数为 **n2**,则有**n0＝n2＋1**
> 4. 若规定**根节点的层数为1**，具有**n个结点的满二叉树的深度h=logn**

> **2.3.1 顺序存储：**
> 顺序结构存储就是使用**数组**来存储，一般使用数组只适合表示**完全二叉树**，因为不是完全二叉树会有空间的浪费。
>
> 而现实中使用中**只有堆才会使用数组来存储**，关于堆我们后面的章节会专门讲解
>
> 二叉树顺序存储在**物理上(实际在内存中)是一个数组**，在**逻辑上(想象)是一颗二叉树**
>

>
> **2.3.2 链式存储：**
> 二叉树的链式存储结构是指，用链表来表示一棵二叉树，即用链来指示元素的逻辑关系。 通常的方法是链表中每个结点由三个域组成，数据域和左右指针域，**左右指针**分别用来给出该结点**左孩子和右孩子**所在的链结点的存储地址 。链式结构又分为**二叉链和三叉链**，当前我们学习中一般都是二叉链，后面课程学到高阶数据结构如红黑树等会用到三叉链。

> **中序**(左**根**右):**"BGDACEFH"**
>
> 1. **先处理B的左子树**：但B没有左孩子，所以左子树处理完毕。
> 2. **访问根节点B本身**。这是访问到的**第一个节点**，所以中序序列开头是 `B`。
> 3. **最后处理B的右子树**（以D为根的树）。对于D的子树，同样用中序规则：先左(G)，再根(D)，没有右。所以访问顺序是 G -> D。
>
> **所以，对于子树B，中序遍历结果是：B -> G -> D。**
>
> 
>
> **后序**(左右**根**):**"GDBEHFCA"**
>
> 1. **先处理B的左子树**：B没有左孩子，所以左子树处理完毕。
> 2. **然后处理B的右子树**（以D为根的树）。对于D的子树，同样用后序规则：先左(G)，再右(无)，最后根(D)。所以访问顺序是 G -> D。
> 3. **最后，等B的左右子树都处理完毕，才访问根节点B本身**。
>
> **所以，对于子树B，后序遍历结果是：G -> D -> B。**
